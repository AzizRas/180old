# Как залить обновление — по шагам

Инструкция под ваш экран: cPanel → Менеджер файлов → `public_html`.

Весь процесс — 10 минут. База и загруженные фото не пострадают.

---

## Шаг 0. Резервная копия (2 минуты, не пропускайте)

В Менеджере файлов:

1. Зайдите в папку **`data`** → выделите файл **`level180.sqlite`** →
   вверху кнопка **Загрузить** (та, что со стрелкой вниз). Файл скачается
   вам на компьютер. Это вся ваша база.
2. Вернитесь в `public_html` → выделите **`config.php`** → снова **Загрузить**.
   Из него мы возьмём ваши ключи.

Положите оба файла в отдельную папку на компьютере. Если что-то пойдёт не
так — вернёте их обратно, и всё будет как было.

---

## Шаг 1. Откройте старый config.php и выпишите 4 значения

Откройте скачанный `config.php` в Блокноте и найдите строки:

```php
'secret'         => '...',      ← скопируйте
'admin_password' => '...',      ← скопируйте
'api_key'        => 'AIza...',  ← скопируйте (это ключ Gemini)
```

Плюс, если вы уже вписывали номера карт в `donate` — скопируйте и их.

Держите этот файл открытым, он понадобится через два шага.

---

## Шаг 2. Загрузите архив

1. В Менеджере файлов убедитесь, что вы в **`public_html`**
   (путь виден в поле слева вверху).
2. Нажмите **Загрузить** (кнопка со стрелкой вверх).
3. Перетащите файл **`180kun-v2.1-upload.zip`**.
4. Дождитесь 100% и нажмите **Go Back to…** внизу страницы.

---

## Шаг 3. Распакуйте

1. Нажмите **Перезагрузить**, чтобы увидеть загруженный архив.
2. Выделите **`180kun-v2.1-upload.zip`** одним кликом.
3. Вверху нажмите **Извлечь** → в окне должен быть путь
   `/home/ayzionxv/public_html` → **Extract Files**.

Архив собран так, что файлы лягут прямо в `public_html`, без лишней
вложенной папки. Старые файлы перезапишутся новыми — это нормально.

**Папки `data` и `uploads` не пострадают:** в архиве внутри них лежат
только служебные файлы `.htaccess`, самой базы там нет.

4. Закройте окно результата и нажмите **Перезагрузить**.

Теперь в списке должны появиться новые файлы: `cron.php`, `tg.php`,
`go.php`, `check.php`, `config.local.sample.php`, `CRON.md`.

---

## Шаг 4. Перенесите свои ключи (самое важное)

Чтобы при следующих обновлениях больше не переносить ключи руками,
в этой версии они живут в отдельном файле.

1. Выделите **`config.local.sample.php`** → вверху **Переименовать** →
   новое имя: **`config.local.php`** → Rename File.
2. Выделите **`config.local.php`** → **Редактировать** → Edit.
3. Впишите значения из старого конфига (шаг 1):

```php
'secret'         => 'сюда старый secret',
'admin_password' => 'сюда ваш пароль админки',
'cron_key'       => 'придумайте любой набор букв и цифр',
'admin_phone'    => '998ВАШНОМЕР',

'ai' => [
    'api_key' => 'сюда ключ Gemini',
],

'donate' => [
    'cards' => [
        ['title' => 'Uzcard', 'number' => 'ваш номер карты', 'holder' => 'ФАМИЛИЯ ИМЯ'],
    ],
    'contact' => '@ваш_телеграм',
],
```

4. **Save Changes**.

`secret` обязательно старый — иначе все, кто уже заходил, разлогинятся.
`admin_phone` — это ваш номер: под ним вы войдёте в приложение как админ.

> На будущее: этот файл при обновлениях **не трогается**. Просто
> перезаписываете всё остальное, и ключи остаются на месте.

---

## Шаг 5. Проверьте

Откройте в браузере: **`https://180kun.online/check.php`**

Все строки должны быть зелёными. Что может быть красным и почему:

| Строка | Что делать |
|---|---|
| Личный конфиг config.local.php — НЕТ | вернитесь к шагу 4 |
| Ключ cron задан — НЕТ | впишите `cron_key` в config.local.php |
| Пароль админки изменён — НЕТ | впишите `admin_password` |
| GD — нет | включите расширение gd в cPanel → Select PHP Version |
| Папка uploads не доступна на запись | выделите `uploads` → **Права** → 0755 |

Потом откройте **`https://180kun.online/`** — должна открыться Конституция
с кнопкой «Начать свои 180 дней».

---

## Шаг 6. Уберите лишнее

Когда всё зелёное, выделите и удалите:

* `check.php`
* `check-ai.php`
* `180kun-v2.1-upload.zip`

Заодно можно удалить остатки от заглушки хостинга, они не нужны:

* `parking-page.shtml`
* папку `nc_assets`

`error_log` тоже можно удалить — он создастся заново, если будут ошибки.
Кстати, загляните в него перед удалением: если там что-то есть, покажите
мне, я посмотрю.

---

## Шаг 7. Cron

Отдельная инструкция — в файле **`CRON.md`**. Это обязательный шаг:
без него не будет ни персональных заданий на неделю, ни сообщений коуча.

Коротко: cPanel → **Cron Jobs** → Minute `*/10`, остальные поля `*` →
Command:

```
curl -s "https://180kun.online/cron.php?key=ВАШ_CRON_KEY" > /dev/null 2>&1
```

---

## Шаг 8. Первый вход

1. Откройте `https://180kun.online/`
2. «Начать свои 180 дней» → введите свой номер (тот, что в `admin_phone`).
3. Код придёт **не по SMS**, а появится прямо на экране — сейчас включён
   режим `log`, договора с SMS-провайдером пока нет. Это нормально для
   старта и для тестов.
4. Введите код → имя → три вопроса → вы внутри.

Админка: `https://180kun.online/admin.php`, пароль из `config.local.php`.

---

## Если что-то сломалось

Верните два файла из шага 0 (`config.php` и `data/level180.sqlite`) на
место — сайт вернётся к прежнему состоянию.

И покажите мне, что написано в `error_log` — разберёмся.
